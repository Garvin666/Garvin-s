关于这份作品集

静室工作室是一份作品集模板的示例站点，为设计师与摄影师准备——以视觉展示为核心，把作品放在最先被看到的位置，其余信息退到后面。

整套模板为单文件、零外部依赖：作品缩略图由 CSS 渐变实时绘制，不加载任何图片或字体资源。你可以把作品替换成自己的图，结构完全不用动。

页面适配移动端，在手机上以单列呈现，触控区域按手指尺寸留足。
